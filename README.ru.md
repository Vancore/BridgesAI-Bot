# Bridges AI 🌉

[![Python Version](https://img.shields.io/badge/python-3.10%2B-blue.svg)](https://www.python.org/)
[![Telegram](https://img.shields.io/badge/Telegram-Bot%20API-blue?logo=telegram)](https://core.telegram.org/bots)
[![Gemini](https://img.shields.io/badge/Google-Gemini%20API-brightgreen?logo=google)](https://aistudio.google.com/)

**Bridges AI** — быстрый, безопасный и конфиденциальный Telegram-бот для взаимодействия с передовыми моделями искусственного интеллекта Google Gemini.

Проект построен по концепции **BYOK (Bring Your Own Key)**: пользователи подключают свои персональные API-ключи от Google AI Studio. Это исключает наценку на токены, обеспечивает прямой доступ без посредников и гарантирует полную приватность персональных данных.

## ✨ Основные возможности

- 🔑 **Архитектура BYOK (Свой ключ):** Прямое соединение с Google API без перепродажи трафика и скрытых посредников.
- 🔐 **Шифрование данных на лету:** API-ключи пользователей шифруются симметричным алгоритмом **Fernet (AES-128-CBC + HMAC-SHA256)** до момента записи в SQLite.
- 💬 **Контекстный диалоговый движок:** Поддержка истории сообщений со строгим чередованием ролей (`user` ↔ `model`), защитой от пустых промптов и автоочисткой старых диалогов (скользящее окно на 40 сообщений).
- 👥 **Работа в любых чатах:**
  - **Личные сообщения:** Полноценный контекстный диалог с ИИ.
  - **Группы и супергруппы:** Вызов по команде `/ai <вопрос>` с индикацией набора текста.
  - **Inline-режим:** Вызов ассистента в любом чате через `@ИмяБота <вопрос>`.
- ⭐️ **Монетизация через Telegram Stars:** Встроенные тарифы подписки (1 месяц, 3 месяца, Навсегда) с нативной оплатой звёздами Telegram (`XTR`).
- ⚡ **Отказоустойчивая БД SQLite:** Работа базы в режиме **WAL (Write-Ahead Logging)** с реентерабельной блокировкой потоков (`threading.RLock`).
- 🛡️ **Защита от сбоев и разметки:** Защита от спама (Anti-flood), экранирование спецсимволов и кастомный парсер Markdown в HTML с изоляцией блоков кода `<pre>` и `<code>`.

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/Vancore/BridgesAI-Bot
cd BridgesAI-Bot
```

### 2. Создание и активация виртуального окружения
```bash
# Linux / macOS
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Генерация ключа шифрования и настройка
Сгенерируйте 32-байтный криптографический ключ Fernet:
```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

Заполните файл `config.py`:
```python
TOKEN = "1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ"   # Токен вашего Telegram-бота
ADMIN_ID = 123456789                              # Ваш числовой Telegram ID
encryption_key = b"ВСТАВЬТЕ_СГЕНЕРИРОВАННЫЙ_КЛЮЧ=" # Ключ шифрования Fernet в байтах
```

### 5. Запуск бота
```bash
python bot.py
```

## 🕹️ Команды бота

### Для пользователей
| Команда | Описание |
| :--- | :--- |
| `/start` | Запуск бота, инструкция по подключению ключа и старт 14-дневного триала |
| `/clear` | Полная очистка контекста текущего диалога |
| `/deletekey` | Безвозвратное удаление API-ключа и всей истории из базы данных |
| `/status` | Проверка оставшихся дней подписки и статуса аккаунта |
| `/sub` | Меню продления доступа с оплатой через Telegram Stars |
| `/ai <вопрос>` | Запрос к ИИ в групповых чатах |

### Инлайн-режим (Inline Mode)
Наберите `@ИмяВашегоБота <запрос>` в строке ввода любого диалога для получения мгновенного ответа.

### Для администратора
| Команда | Формат | Описание |
| :--- | :--- | :--- |
| `/stats` | `/stats` | Метрики системы: общее число пользователей, активные подписки, размер БД |
| `/give` или `/get` | `/give <uid> <дни>` | Ручное начисление или продление дней Pro-доступа по ID пользователя |
